# practica09 – Galería de Imágenes (Jetpack Compose)

Desarrollo Móvil Nativo · Android 14 (API 34)

- Cuadrícula adaptativa con `LazyVerticalGrid`
- Carga asíncrona con Coil (`SubcomposeAsyncImage`) con indicador de carga y manejo de errores
- Reto: al tocar una imagen se abre un `Dialog` con la imagen ampliada (estado en `GaleriaScreen`)

## Cómo abrirlo
1. Android Studio (Koala o más reciente) → File > Open → carpeta `practica09`
2. Esperar el Gradle Sync (necesita internet)
3. Ejecutar en emulador o dispositivo con Android 14
