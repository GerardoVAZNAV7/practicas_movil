# Prácticas de Desarrollo Móvil Nativo

Repositorio para las prácticas y proyectos de la materia de **Desarrollo Móvil Nativo**, enfocado en el ecosistema de Android utilizando Android Studio.

## 🛠️ Requisitos del Entorno

Para ejecutar y probar las prácticas de este repositorio, asegúrate de contar con lo siguiente:

*   **IDE:** [Android Studio](https://developer.android.com/studio) (versión Hedgehog o superior recomendada).
*   **SDK Target / Versión de Android:** Android 14 (API nivel 34) como objetivo principal.
*   **Lenguaje:** Kotlin / Java (según se indique en cada práctica).
*   **Dispositivo:** Emulador configurado con Android 14 o un dispositivo físico con depuración USB habilitada.

## 📂 Estructura del Repositorio

Cada práctica se encuentra organizada en su propio directorio dentro de este repositorio:

```text
/
├── Practica01/   # Hola Mundo interactivo
├── Practica02/   # Calculadora Basica
├── Practica03/   # Intent y Navegacion
├── Practica04/   # Controles Avanzados
└── ...
```

## 🚀 Cómo Empezar

1. Clona este repositorio en tu máquina local:
   ```bash
   git clone https://github.com/GerardoVAZNAV7/practicas_movil.git
   ```
2. Abre **Android Studio**.
3. Selecciona **Open** (Abrir) y busca la carpeta de la práctica que deseas ejecutar.
4. Espera a que Gradle sincronice las dependencias y ¡listo!
