# Mini Proyecto 02 - Administrador de Tareas Locales (Android 14)

App con Jetpack Compose y Room Database.
- TopAppBar con acciones: borrar completadas y menu desplegable (filtrar y ordenar)
- LazyColumn con tareas: marcar como completada, editar y eliminar
- Persistencia local con Room (Entity Tarea, TareaDao, AppDatabase Singleton)
- Arquitectura: data / domain / presentation con ViewModel
